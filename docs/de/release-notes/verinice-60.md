# verinice 60

Veröffentlichung: 25. September 2026 (voraussichtlich)

Die folgenden Neuerungen stehen Anwenderinnen und Anwendern mit dem Release von **verinice 60** zur Verfügung.

## Detailverbesserungen und Bugfixes
<!-- epics/276 -->

- Fehlende Reports in den Datenschutz-Domänen DS-GVO (DE) und GDPR (INT) ergänzt.
- Berechtigungen auf der Seite Risikodefinitionen ergänzt.
- Inkonsistentes Verhalten der Checkbox Unitzugriffskontrolle behoben.
- Unzulässigen Subtypen bei der Erstellung eines Scope-Objekts korrigiert.
- Navigation im Formular Externer Dienstleister in den ISO-Domänen behoben.
- Verbesserung der Meldung, wenn noch keine Objekte aus einem Katalog angewendet wurden.
- Layout-Verbesserungen im Dialog CSV-Import.
- Anpassung der NIS2 (DE) Reports an das NIS2UmsuCG. 
- Anpassung des Sicherheitsvorfalls in der Domäne NIS2 (INT) an andere Domänen.
- HTTP 500 Fehler bei der Abfrage von Attributwerten behoben.
- Obsolete Feature Flags entfernt.
