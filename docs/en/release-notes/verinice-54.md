# verinice 54

Release Date: May 22, 2026

The following new features are available to users with the release of **verinice 54**.

## New GDPR (INT) Domain
<!-- epics/250 -->

Release of the English-language domain **GDPR (INT)** for the internationally applicable version of the GDPR.

## New Domain NIS2 (INT)
<!-- epics/249 -->

Release of the English-language domain **NIS2 (INT)** for the internationally applicable version of NIS2.

## New Domain ISO 27001 (INT)
<!-- epics/248 -->

Release of the English-language domain **ISO 27001 (INT)** for the internationally applicable ISO EN standards.
