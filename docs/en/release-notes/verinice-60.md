# verinice 60

Release Date: September 25, 2026 (tentative)

The following new features will be available to users with the release of **verinice 60**.

## Detail Improvements and Bug Fixes
<!-- epics/276 -->

- Missing reports in the data protection domains DS-GVO (DE) and GDPR (INT) have been added.
- Permissions added to the Risk Definitions page.
- Inconsistent behavior of the “Unit Access Control” checkbox fixed.
- Invalid subtypes when creating a scope object corrected.
- Navigation issues in the External Service Provider form within the ISO domains fixed.
- Improved message when no objects from a catalog have been applied yet.
- Layout improvements in the CSV Import dialog.
- Adapted NIS2 (DE) reports to comply with the NIS2UmsuCG.
- Aligned the security incident in the NIS2 (INT) domain with other domains.
- Fixed an HTTP 500 error when querying attribute values.
- Removed obsolete feature flags.
